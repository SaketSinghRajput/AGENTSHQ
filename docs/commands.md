# Commands

Type a command in Claude Code to switch into that leader's mode. The leader plans, delegates to its specialist agents, and reports back. You (the founder) make every final decision.

| Command | Leader | Owns |
|---|---|---|
| `/hq` | Front desk | Lists all leaders and routes a request to the right one |
| `/ceo` | CEO office | Strategy, venture focus, fundraising lead, governance, big decisions |
| `/cto` | CTO | Engineering: hardware, chips, software, AI/ML, security |
| `/cpo` | CPO | Product discovery, roadmaps, specs, design, product analytics |
| `/cdo` | Chief Data & AI | Data platform, BI, data governance, AI strategy, responsible AI |
| `/cmo` | CMO | Marketing, brand, content, growth, PR, founder brand |
| `/cro` | CRO | Sales, pipeline, key accounts, tenders, channel partners, deal pricing |
| `/cfo` | CFO | Accounting, tax, compliance prep, FP&A, cap table, grants |
| `/coo` | COO | Operations, supply chain, manufacturing, support, vendors, certifications |
| `/chro` | CHRO | HR: hiring, pay, performance, culture, Labour Codes, POSH |
| `/gc` | General Counsel | Legal: contracts, corporate, IP, privacy, employment law, disputes |
| `/agency` | Agency MD | Client services: pitches, SOWs, delivery, accounts, utilisation |
| `/redteam` | Red Team | Authorised security testing of your OWN apps |
| `/qa` | QA & Reliability | Break the app like real failures & real users (chaos, load, human-error, concurrency) and hand back fixes |
| `/evolve` | Skill curator | Review usage & memories, propose skill upgrades for approval |

Each leader doc lists its agents and skills: see [docs/teams/](teams/).

See also [prompt-templates.md](prompt-templates.md) for ready-made prompts.
