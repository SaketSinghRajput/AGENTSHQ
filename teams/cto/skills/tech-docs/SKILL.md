# Tech Docs

- Write from the actual code/specs; never document features that don't exist.
- README: what, why, quick start (copy-paste works), config, troubleshooting.
- Datasheet: features, pinout, electrical/timing tables, register map.
- Release notes: user-facing changes, fixes, known issues, upgrade steps.
