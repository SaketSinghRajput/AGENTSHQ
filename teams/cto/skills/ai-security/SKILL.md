# Ai Security

- Test prompt injection (direct + indirect via documents/web), jailbreaks, tool abuse, data exfiltration.
- Check training-data provenance and poisoning risk; PII memorization tests.
- Output handling: never execute model output without validation.
- Rate limits and abuse monitoring. Report with reproducible prompts.
