# Hil Testing

- Test cards: setup photo/diagram, instruments, steps, pass criteria.
- Cover: power-on, brown-out, temperature (Indian summer 45°C+), dust/vibration where relevant, RF range, battery life, OTA failure/rollback, 72h soak.
- Automate with Python + serial/MQTT; log to CSV; attach plots.
