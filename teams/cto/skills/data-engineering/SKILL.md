# Data Engineering

- Data contract per source: schema, owner, freshness, PII fields.
- Pipelines idempotent, tested, versioned (DVC or dated parquet). Validate with schema checks.
- Labeling guide with examples + inter-annotator agreement.
- Dataset card: source, license, consent, splits (no leakage), class balance.
- Personal data: minimize, pseudonymize, follow privacy-compliance-officer guidance.
