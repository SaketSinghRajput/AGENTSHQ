# Prd Writing

`docs/prd/<feature>.md` sections: Problem · Users/personas (Indian context: language, network, price sensitivity) · Goals / Non-goals · User stories (As a…, I want…, so that…) · Acceptance criteria (Given/When/Then, each testable) · Metrics (north star + guardrails) · Constraints (cost, power, regulatory) · Alpha exit · Beta exit · Open questions.
