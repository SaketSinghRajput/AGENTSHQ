# Beta Program

- Plan: cohort (5-30 users/sites), scenarios, consent, duration, success metrics.
- Feedback template + crash/telemetry collection (with consent).
- Weekly triage: bug vs feature vs noise; severity; owner.
- Exit report with go/no-go recommendation and evidence.
