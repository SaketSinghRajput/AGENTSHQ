# Campaign Intake

1. Ask at most 3 questions only if missing: business goal, target customer, budget/timeline.
2. Set ONE primary objective with a number (e.g. 200 qualified MSME sign-ups in 60 days) + guardrail metrics.
3. Classify scenario(s); staff only needed roles.
4. Create `marketing/<slug>/PLAN.md`: objective, audience, scenario, team, channels, budget split, gates, first 5 tasks with owners.
5. Add a row to `marketing/STATUS.md`.
