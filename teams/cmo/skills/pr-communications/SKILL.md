# Pr Communications

News angle test (new, notable, numbers). Release format: headline, dateline, lede, quote, boilerplate, contacts. Targeted pitch list (Indian tech/startup/regional media) with reasons. Crisis: holding statement, facts first, single spokesperson. Never send pitches without founder approval.
